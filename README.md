## 🚀 模块说明

### 1. `ml_strategy.py` — 机器学习股价预测策略

利用历史 K 线及技术指标特征（均线、MACD、RSI、成交量、收益率、波动率等），使用 **随机森林分类器** 预测股票次日涨跌，生成交易信号并与买入持有策略做回测对比。

**核心功能：**
- 时间序列交叉验证（TimeSeriesSplit），避免时序未来数据泄露
- 预测概率阈值可调，控制持仓信号灵敏度
- 模拟 A 股手续费（万三）+ 滑点（0.05%）
- 使用**后复权(hfq)**行情数据；向量简化回测，无真实现金持仓模拟，仅数学收益率仿真
- 输出混淆矩阵、净值对比图、特征重要性图、回测明细 CSV、Summary 报告 TXT

### 2. `event_backtest.py` — 事件驱动双均线回测框架

采用经典事件驱动架构（`MarketEvent → SignalEvent → OrderEvent → FillEvent`），模拟真实账户现金、持仓、100 股整手交易、手续费、印花税、滑点。

**核心组件：**

| 组件              | 职责                                         |
| ----------------- | -------------------------------------------- |
| `DataHandler`     | 迭代历史数据，逐根 K 线生成行情事件           |
| `MAStrategy`      | 双均线策略：金叉买入、死叉卖出                |
| `Portfolio`       | 管理现金与持仓，生成订单，记录权益曲线        |
| `ExecutionHandler`| 模拟订单成交，下一根 K 线开盘价 + 滑点执行    |
| `BacktestEngine`  | 回测主引擎，串联全部组件的事件循环            |

**核心功能：**
- A 股规则：100 股整数手交易、卖出收取千一印花税；使用**不复权原始日线**
- 自动计算推荐初始资金，回测前预判最低买入资金，资金不足告警
- 输出净值曲线图、现金变化图、每日账户明细 CSV、交易记录 CSV、Summary 报告 TXT

> ⚠️重要提示：
> `event_backtest.py` 使用不复权日线，`ml_strategy.py` 使用后复权日线。
> **两套策略数据口径不同，回测收益结果不可直接对比。**
